# JIZURA — 가사 모션 비디오 메이커

가사를 입력하면 브라우저에서 리릭 모션 영상을 자동으로 구성하고 MP4로 내보낼 수 있습니다. JIZURA는 860개의 연출 부품과 27개 스타일을 조합하며, 시드를 바꾸거나 **자동으로 만들기**를 누르면 다른 구성을 만들 수 있습니다.

**[한국어판 열기](https://852wa.github.io/JIZURA/ko/)** · [日本語](https://852wa.github.io/JIZURA/) · [English](https://852wa.github.io/JIZURA/en/) · [繁體中文](https://852wa.github.io/JIZURA/zh-hant/) · [简体中文](https://852wa.github.io/JIZURA/zh-hans/) · [Bahasa Indonesia](https://852wa.github.io/JIZURA/id/) · [Tiếng Việt](https://852wa.github.io/JIZURA/vi/) · [일본어 가이드](README.md)

일본어·영어·번체 중국어·간체 중국어·한국어·인도네시아어·베트남어 브라우저판은 같은 프로젝트 형식과 브라우저 저장 데이터를 사용합니다. 편집기 상단의 언어 선택 메뉴로 UI 언어를 바꿔도 가사와 설정은 그대로 유지됩니다.

**버전: v0.9.0** · [변경 기록](CHANGELOG.md)

<details>
<summary><h2>빠른 시작</h2></summary>

1. 왼쪽 가사 입력란에 한 줄당 한 프레이즈씩 가사를 붙여 넣습니다.
2. 필요하면 음원을 불러옵니다. JIZURA가 박자를 감지해 컷을 맞출 수 있으며, **탭으로 동기화**에서 각 줄이 시작될 때 Space를 눌러 직접 타이밍을 지정할 수도 있습니다.
3. **자동으로 만들기**(또는 R)를 눌러 스타일, 분위기, 움직임, 배색, 구성을 랜덤으로 만듭니다. **이전 / 다음**으로 버전을 오가거나 **이 부분만 변경**으로 일부만 다시 만들 수 있습니다.
4. 화면비, 해상도, 프레임레이트를 선택하고 MP4로 내보냅니다. 고급 모드에서는 PNG 시퀀스, 투명 PNG, 합성용 배경, 개별 기법 설정도 사용할 수 있습니다.

<details>
<summary><h3>한글 가사</h3></summary>

가사 입력란 아래의 **가사 언어**는 기본값이 **자동 감지**입니다. 한글이 포함된 가사는 자동으로 한국어로 감지되며, 각 스타일의 일본어 글꼴은 비슷한 인상의 한국어 글꼴로 바뀝니다.

예를 들어 Noto Sans JP 계열은 Noto Sans KR, Noto Serif JP 계열은 Noto Serif KR로 대응하고, Dela Gothic One은 Black Han Sans, 둥근 글꼴은 Jua, 손글씨 계열은 Gowun Batang 또는 Nanum Brush Script 등으로 대응합니다. 필요한 글꼴은 Google Fonts에서 현재 구성에 필요한 것만 불러옵니다.

가사 표기법:

- `새벽의 색을/기억하고 있어` — `/` 위치에서 컷 분할
- `*투명*` — 강조
- 줄 끝의 `!` — 플래시와 흔들림
- `가사|메모` — 주석용 작은 글자
- `[01:23.45]가사` — LRC 타임스탬프
- `[간주 8]` — 가사 없이 배경과 장식만 나오는 8초 간주. 숫자를 생략하면 4초이며, 탭 동기화로 길이를 맞출 수도 있습니다.
- `# 주석` — 무시되는 줄

<summary><h3>줄 편집·컷 교체·잠금·반복</h3></summary>

- **줄 편집**: 줄 목록의 연필 버튼을 누르거나 가사를 더블 클릭해 수정합니다. 줄마다 컷 수를 자동 또는 1~6개로 지정할 수 있습니다. ◎ 버튼으로 해당 줄부터 탭 동기화를 다시 하고, Backspace로 직전 탭을 취소합니다.
- **타이밍**: 타임라인 위의 줄 경계를 드래그해 시작 시각을 바꿉니다. `+` / `−` 또는 휠로 확대·축소하고, Shift를 누르면 박자에 맞춰 붙지 않습니다. 가사와 타이밍 수정은 **되돌리기** 또는 Ctrl+Z로 취소합니다.
- **컷 교체**(고급 모드): 미리보기 아래의 레이아웃·등장·유지·퇴장·장식·글자 효과·배경·카메라·전환을 눌러 현재 컷의 기법만 바꿉니다. **자동**으로 수동 지정을 해제할 수 있습니다. 줄 목록에서도 컷별 레이아웃을 선택할 수 있고, 현재 컷의 **셔플 / 자동 생성**으로 그 컷만 다시 만들 수 있습니다. 다른 컷의 구성은 유지됩니다.
- **잠금**(고급 모드): 기법 분류 옆의 자물쇠는 해당 분류의 ON/OFF 선택을, 연출 슬라이더·플래시·프레임 홀드 옆의 자물쇠는 해당 값을 고정합니다. 자동 생성 후에도 유지되며 프로젝트에 함께 저장됩니다. 줄의 자물쇠는 그 줄의 구성 전체를 고정합니다.
- **반복**: 재생 버튼 옆의 **반복**을 누를 때마다 전체 → 줄 → 컷 → 반복 없음으로 바뀝니다. **줄 반복 / 컷 반복** 구간은 타임라인에 표시됩니다.

**현재 버전**에는 실제로 사용 중인 글꼴 이름이 표시됩니다. 넓은 화면에서는 미리보기와 타임라인을 고정한 채 가사·줄 목록과 설정을 각각 스크롤할 수 있습니다.

간단 모드나 **연출** 탭의 **통일감**은 파트별 레이아웃과 움직임을 맞추고, 반복되는 가사는 같은 방식으로 보여 줍니다. **문자 정렬**은 글자 간격·크기와 연출의 겹침을 조절하고, 가사를 음성보다 0.2초 먼저 보여 줍니다. 두 설정은 각각 켜거나 끌 수 있습니다.

<summary><h3>타이포그래피·키네틱·호러 부품</h3></summary>

자동 생성 버튼 아래와 **기법** 탭 위에서 다음 세트를 선택할 수 있습니다. **추가 연출도 사용**과 별도로 적용됩니다.

- **타이포그래피 부품 사용**(기본 켬, T 표시): 선·숫자·글자 조판을 중심으로 구성하는 50개 부품입니다. 거대 글자, 십자 조판, 루비 주석, 괘선, 자간, 괄호 등을 사용합니다.
- **키네틱 부품 사용**(기본 켬, K 표시): 단어를 하나씩 움직이는 51개 부품입니다. 쌓기, 회전, 교체, 글자 속으로 들어가기, 단어별 등장과 카메라 이동 등을 사용하며, 음원이 있으면 단어 전환을 박자에 맞춥니다.
- **호러 연출도 사용**(기본 끔, H 표시): 손전등·문틈·감시 화면·노이즈 등의 52개 부품과 **폐허 / 심야의 녹화 / 저주의 편지** 스타일을 추가합니다. 자동 생성에 **호러** 분위기가 추가되고 약 절반의 확률로 선택됩니다. 자동 생성에서는 호러 분위기일 때만 호러 부품을 사용합니다.

After Effects 패널에서도 세 세트를 모두 사용할 수 있습니다. AE에서는 박자에 맞춘 단어 전환을 컷 길이에 균등하게 나누어 배치합니다.

<summary><h3>스마트폰 모드</h3></summary>

좁은 화면이나 터치 기기에서는 **스마트폰 / 간단 / 고급** 모드를 선택할 수 있으며, 처음에는 스마트폰 모드로 열립니다. 자동 생성 버튼과 미리보기는 위에 고정되고, 줄 목록에서는 누른 줄의 편집 도구만 펼쳐집니다. 각 영역의 제목을 눌러 접거나 펼칠 수 있으며, 저장·열기·초기화는 **메뉴**에 모여 있습니다.

스마트폰 모드는 기본 해상도가 720p이고, 1080p를 넘는 설정도 최대 1080p로 내보냅니다. 더 큰 해상도는 고급 모드에서 선택합니다. 지원되는 브라우저에서는 내보내는 동안 화면 꺼짐을 막고, 다른 앱으로 잠시 전환해도 내보내기가 실패한 것으로 처리하지 않습니다. 완료 후 **공유해서 저장**으로 사진 앱 등에 저장할 수 있습니다.

</details>

<details>
<summary><h3>미리보기·내보내기·프로젝트</h3></summary>

재생 버튼 옆 음량 조절은 미리보기에만 적용되며, 내보낸 음원은 원래 음량을 유지합니다. **내보낼 범위**로 선택한 줄만 내보낼 수 있습니다. 불러온 음원은 브라우저에 보관되어 다시 열어도 유지됩니다. 브라우저가 AAC 음원을 내보낼 수 없으면 MP4와 함께 WAV도 저장합니다.

**투명 PNG 전경/후경 (ZIP)**은 프레임마다 후경(배경 그래픽과 가사 뒤 장식)을 `back/`, 전경(가사·장식·고스트·HUD)을 `front/`에 저장합니다. 전경을 후경 위에 겹치면 일반 화면과 같은 모습이 됩니다. **가운데 비우기(캐릭터용)**는 가사와 연출을 줄마다 번갈아 가로 화면에서는 좌우, 세로 화면에서는 위아래에 배치합니다. 세로 화면은 좌우 배치도 선택할 수 있으며, 배경과 화면 효과는 전체에 적용됩니다.

MP4는 조금씩 처리하며, GPU 인코더가 실패하면 소프트웨어 인코더로 다시 시도합니다. Chrome / Edge의 **큰 동영상용(파일에 바로 저장)**은 선택한 파일에 바로 기록합니다.

**저장 / 열기**로 `.jizura.json` 프로젝트를 관리하고, **AE용 내보내기**로 After Effects에서 편집할 구성 데이터를 저장합니다. **가사 지우기**는 가사·줄별 타이밍·설정·내보낼 범위를 지우며 Ctrl+Z로 복구할 수 있습니다. **초기화**는 확인 후 음원·설정·기록까지 지웁니다.

<summary><h2>빌드</h2></summary>

저장소 루트에서 `python3 build.py`를 실행합니다. 다음 7개 언어판이 각각 단일 HTML 파일로 생성됩니다.

- 일본어: `index.html`
- 영어: `en/index.html`
- 번체 중국어: `zh-hant/index.html`
- 간체 중국어: `zh-hans/index.html`
- 한국어: `ko/index.html`
- 인도네시아어: `id/index.html`
- 베트남어: `vi/index.html`

한국어 UI 번역은 `app/i18n_ko.py`와 `app/korean.py`, 부품명은 `app/korean.js`에서 관리합니다. 번역을 수정한 뒤 다시 빌드해 `ko/index.html`에 반영합니다. 버전은 `VERSION`, 변경 기록은 `CHANGELOG.md`에서 관리합니다.

GitHub Pages는 저장소 루트에서 배포합니다. 한국어판 주소는 `/JIZURA/ko/`이며, HTML 파일을 내려받아 로컬에서 열 수도 있습니다. 한국어 UI는 브라우저판에 제공되며, After Effects 패널의 UI는 일본어·영어판입니다. **AE용 내보내기**의 JSON 형식과 한국어 가사 감지·글꼴 매핑은 공통으로 사용합니다.

</details>
